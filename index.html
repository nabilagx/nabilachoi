FLAGSHIP_01 • WEB / FINTECH

KOIN — Digital School Wallet Platform

A full-stack school digital wallet PWA that connects NFC-based student payments, real-time balance synchronization, parental spending controls, and digital top-ups into one transparent school financial ecosystem.

The Problem

Cash friction in school cafeterias, zero parental visibility on allowances, and manual reconciliation risks.

The Solution

NFC physical cards paired with Next.js PWA, optimistic balance updates, and database transactional policies.

Next.js 14 TypeScript Supabase PostgreSQL RLS NFC Card UID PWA

FLAGSHIP_02 • EDGE ML / HEALTHCARE IOT

PANDA — Patient Ambient Notification & Danger Analysis

An end-to-end healthcare IoT system engineered for bedridden stroke patients—combining multi-sensor ambient monitoring, telemetry streaming over MQTT, and a Random Forest classifier paired with automated AC climate intervention.

The Problem

Paralyzed stroke patients cannot verbalize thermal discomfort or agitation, triggering critical stress spikes.

The Solution

ESP32 sensor fusion feeding a Random Forest model that activates an IR blaster to modulate room AC automatically.

ESP32 (C++) DHT11 / PIR / LDR MQTT (HiveMQ) Scikit-Learn Random Forest IR Blaster

SENSOR → TELEMETRY → ACTUATOR PIPELINE

FIRMWARE + ML
[01] SENSOR NODE (ESP32)
DHT11 (Temp/Humid) + PIR (Agitation) + LDR (Light) → Moving Average Filter
↓ [ MQTT Telemetry over HiveMQ Broker ]
[02] INFERENCE ENGINE
Scikit-Learn Random Forest Classifier → Predicts: Thermal Discomfort / Agitation
↓ [ Safety Rule Check & Actuation Command ]
[03] ACTUATOR LAYER
ESP32 IR Blaster fires modulated 38kHz pulse → Regulates AC target temperature
